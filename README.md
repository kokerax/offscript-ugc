# OFFSCRIPT — UGC Ajansı

Türkçe, mobil uyumlu UGC ajansı web sitesi. Büyük video sahneleri, kaydırmalı geçişler, sektör filtreleri ve tam uzunlukta video oynatıcı içerir.

## Medya

Galerideki dokuz video, site sahibi tarafından 27 Ekim 2026 tarihinde paylaşılan UGC seçkisinden hazırlanmıştır. Kaynak dosyalar bu depoya dahil edilmez. Web kopyaları H.264/AAC biçimindedir; sessiz kısa önizlemeler görünür olduklarında yüklenir. Tam videolar yalnız oynatıcı açıldığında yüklenir. Görünen markalar için performans sonucu veya iş birliği iddiası eklenmemiştir.

Footer'daki stüdyo görseli yapay zekâ ile hazırlanmış temsili bir görseldir.

## Yayın

Statik dosyalar doğrudan GitHub Pages üzerinden sunulur. Göreli dosya yolları sayesinde proje alt yolunda da çalışır. Yerel önizleme için bu dizin bir HTTP sunucusuyla açılmalıdır.
